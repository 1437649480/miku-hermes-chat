# 操作指令参考

本文件列出初音未来微信聊天机器人的所有可用指令。

***

开机

这些命令在 WSL 终端中运行（先进入 WSL：`wsl.exe -d Ubuntu-24.04`）：

```bash
# 进入 WSL 后可执行：
hermes                 # 启动 Hermes 交互式聊天
hermes gateway run     # 启动微信网关后台运行
hermes gateway stop    # 停止微信网关
```

> .bat 快捷脚本位于 `D:\桌面\opencil\mikuchat\` 目录下（原在根目录，整理后移入此文件夹）。

## 语音指令

语音模式存储在 WSL 中 `/home/yaya/.hermes/gateway_voice_mode.json`，按 `{platform}:{user_id}` 区分。

### /voice — 控制语音模式

| 指令               | 模式             | 说明                        |
| ---------------- | -------------- | ------------------------- |
| `/voice off`     | `off`          | 纯文字回复，**不发任何语音**          |
| `/voice disable` | `off`          | 同上                        |
| `/voice on`      | `voice_only`   | 仅在**收到语音消息**时回复语音         |
| `/voice enable`  | `voice_only`   | 同上                        |
| **`/voice tts`** | **`all`** ← 当前 | **所有回复都带语音（TTS 合成）**      |
| `/voice status`  | —              | 查看当前语音模式                  |
| `/voice`         | 切换             | `off` ↔ `voice_only` 交替切换 |

### 语音三种模式

| 模式     | 存储值          | 说明               |
| ------ | ------------ | ---------------- |
| 关闭     | `off`        | 纯文字回复，静音         |
| 语音回复   | `voice_only` | 只在收到语音消息时才回复语音   |
| 全量 TTS | `all`        | 所有文字回复都附带 TTS 语音 |

***

## /voiceorder — 控制语音发送顺序

| 指令                   | 效果                       |
| -------------------- | ------------------------ |
| `/voiceorder after`  | 语音在**文字+表情包之后**发送（默认，推荐） |
| `/voiceorder before` | 语音在**文字+表情包之前**发送        |
| `/voiceorder`        | 切换 `after` ↔ `before`    |
| `/voiceorder status` | 查看当前发送顺序                 |

**存储位置：** `/home/yaya/.hermes/gateway_voice_order.json`

## 检查服务状态

```bash
# 在 Windows 双击 检查服务状态.bat
# 或在 WSL 终端执行：
wsl -d Ubuntu-24.04

# Gateway 状态
hermes gateway status

# 在线 API 状态
curl -s http://localhost:8000/health   # DeepSeek API
curl -s http://localhost:8002/health   # Kimi API

# 查看日志
hermes gateway logs --tail 50
```

## 重启服务

```bash
# 方式 1：Windows 双击 启动Miku网关.bat（会自动停止旧进程再启动）

# 方式 2：WSL 终端
bash restart-gateway.sh

# 方式 3：手动
hermes gateway stop
hermes gateway start
```

## TTS 配置

```bash
# 查看当前 TTS 配置
grep -A 10 '^tts:' ~/.hermes/config.yaml

# 切换 TTS provider（编辑 config.yaml）
nano ~/.hermes/config.yaml
# 修改 tts.provider 字段：
#   edge       → Edge TTS 免费语音
#   aivoicelab → 初音未来角色语音（需反代）
#   elevenlabs → ElevenLabs 商用
#   rvc        → RVC 本地音色转换

# 重启网关使配置生效
bash restart-gateway.sh
```

### aivoicelab TTS 配置示例

```yaml
tts:
  provider: aivoicelab
  aivoicelab:
    model: miku
    model_cat: animation
    model_name: us-female-hatsune-miku
    model_lang: japanese
```

## 常用排查命令

```bash
# WSL 内
hermes gateway logs --tail 100                    # 最近 100 行
grep "error\|Error\|ERROR" ~/.hermes/logs/gateway.log | tail -20  # 错误日志
grep "voice\|audio\|tts\|silk" ~/.hermes/logs/gateway.log | tail -20  # 语音相关
grep "sticker" ~/.hermes/logs/gateway.log | tail -20  # 表情包相关
```
