# 初音未来 × Hermes Agent 部署指南

## 快速开始

### 一、准备工作

1. **确认 Hermes 已安装**
   ```bash
   hermes --version
   ```

2. **准备模型 API Key**
   - DeepSeek API Key（推荐）或 Kimi / 其他
   - 或部署免费 API 反代（见 `docs/free-api-guide.md`）

### 二、配置初音未来角色

#### 方式 1：使用 SOUL.md（推荐）

1. 将 `miku.skill/SKILL.md` 的内容作为 SOUL.md 使用

2. 在 WSL 中复制到正确位置：
   ```bash
   cp miku.skill/SKILL.md ~/.hermes/SOUL.md
   ```

3. 重启 Hermes 即可生效
   ```bash
   hermes
   ```

#### 方式 2：使用自定义 Profile

```bash
hermes profile create miku --soul miku.skill/SKILL.md
hermes profile use miku
```

### 三、安装初音未来技能

1. 创建技能目录
   ```bash
   mkdir -p ~/.hermes/skills/miku
   cp miku.skill/SKILL.md ~/.hermes/skills/miku/SKILL.md
   ```

2. 启用技能
   ```bash
   hermes skills enable miku
   ```

### 四、配置微信网关

#### 4.1 运行设置向导

```bash
hermes gateway setup
```

选择 **Weixin** → 等待二维码 → 手机微信扫码 → 确认登录

#### 4.2 配置访问控制（可选）

编辑 `~/.hermes/.env`：

```bash
# 私聊策略
WEIXIN_DM_POLICY=open              # 任何人都可以私聊

# 群聊策略
WEIXIN_GROUP_POLICY=disabled       # 默认禁用群聊

# 白名单
# WEIXIN_ALLOWED_USERS=user_id_1,user_id_2
```

#### 4.3 启动微信网关

```bash
hermes gateway start
```

查看状态：`hermes gateway status`
查看日志：`hermes gateway logs --tail 50`

## 稳定性保障指南

### 常见问题与解决方案

#### 1. 微信连接问题

```bash
# 检查凭证
ls -la ~/.hermes/weixin/accounts/

# 重新扫码
hermes gateway setup
```

#### 2. 会话过期（errcode=-14）

重新扫码登录即可

#### 3. 网络连接问题

```bash
# 测试连通性
curl -I -v https://ilink.bot --connect-timeout 5
```

#### 4. SSL 证书验证失败

```bash
pip install aiohttp cryptography certifi
```

### 高级稳定性配置

```yaml
gateway:
  weixin:
    send_chunk_delay_seconds: 0.5
    send_chunk_retries: 3
    send_chunk_retry_delay_seconds: 2.0
    debug: true

memory:
  enabled: true
  compression: true
```

## 重要注意事项

### 微信账号安全

1. **使用小号** — 建议使用专门的微信小号
2. **避免群发** — 不要在大量群聊中使用
3. **控制频率** — 避免高频消息导致封号
4. **遵守规则** — 遵循微信使用条款

### 备选方案

- **飞书** — 官方 API，稳定可靠
- **企业微信** — 可以与微信互通
- **Telegram** — 全球稳定可用

## 语音功能 (TTS)

### 配置 TTS

有多种 TTS 方案可选，详见 `gateway/tts_interface.py`：

| 方案 | 类型 | 说明 |
|------|------|------|
| Edge TTS | 免费 | 微软神经网络语音，`zh-CN-XiaoxiaoNeural` |
| aivoicelab | 免费（反代） | 初音未来等虚拟角色专属语音 |
| ElevenLabs | 商用 | 最高质量多语种语音 |
| RVC | 本地 | 音色转换，可实现 Miku 声线 |

### 语音指令

| 指令 | 效果 |
|------|------|
| `/voice on` / `/voice enable` | 只对语音消息回复语音 |
| `/voice off` / `/voice disable` | 纯文字，不发语音 |
| `/voice tts` | 所有回复都带语音 |
| `/voice status` | 查看当前语音模式 |
| `/voiceorder after` | 语音在文字+表情包之后发送（默认） |
| `/voiceorder before` | 语音在文字+表情包之前发送 |
| `/voiceorder status` | 查看当前发送顺序 |

详细指令说明见 `docs/操作指令参考.md`。
