# miku-hermes-chat
基于Hermes Agent的零 API 费用虚拟女友系统：通过开源 deepseek-free-api 和 kimi-free-api 实现完全免费多模态对话，支持微信端实时聊天、图片识别、长期记忆（永不丢会话）、上下文压缩、表情包生成及 24×7 保活。 核心亮点：角色扮演：基于 miku.skill 的初音未来女友人格 - 多模态理解：发图即识别描述 - 永久记忆：会话永不自动重置 - 表情包生成：CF Workers AI + Pollinations 双后端 - Token 自动刷新：Windows 任务计划定时续期 - 零 API 费用：完全基于网页版 API 反代 项目包含完整角色 Skill、配置模板、运维脚本及免费生图插件，适合学习 AI 架构或低成本体验虚拟角色对话
